# 1. コアの動詞：「持ちこたえる」

夜のプレイヤーの行為は **「抗う」ではなく「持ちこたえる」**。天使様に**応え続けるために**耐える。

- ★**コア構造（2026-07-22 確定）**：昼の**心身の余白**の割合から、夜の**精力**を算出する（**ゲージではなく数字**で持つ）。天使様が段階的に攻め、精力が削られていく
- 夜は**基本オートで進行**する。プレイヤーが起こせる能動は**残った余白を精力へ追加変換すること**だけ。変換すれば**2発目**が可能になり、夜を長く続けられる
- 眺めるのが主。能動は「もう一発いくか」の一点のみ（連打ではない）ので、**ASMR的な没入を殺さない**
- 昼のトレードオフが生きる：余白を昼で使う（会話・ケア・痛みの回収）か、温存して夜を伸ばすか
- **耐えた量＝ angelFatigue の回復量**。早く終わる＝天使様が十分に回復しない
- 失敗は「負け」ではなく、**「天使様の回復が浅い」という結果**になる
- 結果は**翌日の余白と天使様の疲労度に反映**される

> ⚠️ **混同禁止**：ここで回復するのは **angelFatigue**（天使様の疲労）であって、**主人公の painType ではない**。CURRENT_SPEC のアンチパターン「痛みの数値ゲージ化とゼロ到達＝クリア」に抵触させないこと。夜ケアで主人公の痛みが回復する設計にはしない。

# 2. 入力・ミニゲーム

- ⚠️ **旧案**：タイミングに合わせて **長押し → 離す** の反復。**2026-07-22 のコア確定により見直し対象**（基本オート＋変換の一択に寄せる）
- 指1本で完結する。連打・複雑入力は使わない
- **判定は広く**取る。PERFECT / MISS の精度表示は**入れない**
- **ゲームオーバーなし**。結果はグラデーション
- 主導権の**反転なし**。シチュエーションは変わるが行為は変わらないため、**ミニゲームは1種類のみ**

# 3. ポジション

- **4つ**（28日構成に合わせる）
- 進行によって**置き換わるのではなく、選択肢として増える**
- 解禁後は**いつでもプレイヤーの意思で切替可能**
- **ポジション間の性能差はつけない**（最適解を作らない）

## 3-1. 「今夜の求め」（採用）

- ポジションが **2〜3つに増えた段階**から発生
- **毎晩ではなく、時折**
- 開始前の**立ち絵会話で「それとなく」ヒント**を与える（明示的な指定にしない）
- 応えれば **僅かな回復ボーナス**
- 応えなくても**ペナルティなし**（通常の回復）

> 設計意図：選択を「好み」ではなく**「相手が何を求めているかを読む」**にし、作品の核「必要とされること」に接続する。ただし**「選ばなければならない」にはしない**。頻度・演出・報酬の3つをすべて抑制することで、義務化と攻略対象化を同時に回避する。

# 4. 絵の持ち方（U-07 確定）

- 夜パートは **1枚絵（イベントCG）ベース**。立ち絵ではない
- ★**レイヤー合成方式（2026-07-21 確定）**：ベース **4枚（ポジション別）** の上に、**目／口／汗・湯気**を独立レイヤーで重ねる。各パーツ数枚ずつで、組み合わせにより多彩な表情が出る
- ⚠️ **開眼は廃止**。夜CGでも立ち絵と同じ目（**糸目／切れ長／妖艶**）を使う。D-14 / D-18 の「開眼は夜の1枚絵で」は無効
- **口は輪郭が動く**ため、単純なレイヤー重ねでは破綻する。対策は **B＋C**：
	- **B（普段）**：開口の段階を**輪郭が動かない範囲**に絞る（引き結ぶ／薄く開く／息が漏れる）。切れ長の目の美学と一致し、素材も軽い
	- **C（ここぞ）**：**Z（天使のクライマックス）の瞬間だけ**、輪郭ごと描いた専用の顔を1枚差し込む。口が大きく開き、妖艶＋桃色になる。**全ての抑制が一点で決壊する1枚**
- **湯気は汎用エフェクトレイヤー**を流用（食卓／浴室／夜CGで共用。露出コントロールにも使える）

## 4-1. 差分は「状態連動」にする（重要）

差分レイヤーを「表情のバリエーション」として持たず、**状態から自動的に決まる表現**として持つ。

- **前半：隈 ← angelFatigue**（隈は angelFatigue からの導出値。D-17）
- **後半：表情・汗など残りの差分 ← `bond`**（後半用の値。「二人だけの世界の密度」を表す。**完全非公開**。D-34）
- 隈レイヤーは薄/濃の2枚を**αクロスフェード**して無段階に見せる（D-18）
- 同じベース絵でも、**ケアが進んだ夜とそうでない夜で違う絵に見える**

> ⚠️ **駆動軸を前後半で分けること。** 差分5枚をすべて angelFatigue に連動させると、後半（angelFatigue が0で張り付く）で**絵が固まる**。
→ これが「1ポジションあたり複数夜見る」ことによる**使い回し感への主防波堤**。

# 5. 夜の選択：「おあずけ」択

- ★**夜は回避できない**（2026-07-27）。おあずけは選べるが、**3日経つと天使様側の我慢が効かなくなる**（設定上、止められない）。プレイヤーがどれだけ拒んでも、**天使様は必要とし続ける**。これが「役に立たなくても必要とされる」の最も強い証明になる
- **全 28 夜がケア対象**（一部の夜だけケアにする案は却下）
- ただしプレイヤーは **「おあずけ（今夜はしない）」を選べる**
- おあずけ ＝ **angelFatigue が回復しない → 翌日の余白が減る**。コストはある
- しかし **天使様は咎めない**。肯定して受け入れる

> 設計意図：毎晩必ず求められると「必要とされること」が日常化し、テーマの手触りが薄れる。**断れるからこそ、応じることが選択になる**。
> この構造は懺悔室の3択（話す/ごまかす/黙る、すべて等価に肯定）と**同一の文法**であり、作品全体の一貫性を保つ。

# 5-2. 動機の転換（前半／後半）★重要

- 天使様の疲労は **14日目前後で概ね取り除ける**
- **前半（1〜14日）**：回復させるためにやる。**目的のある行為**。結果は **angelFatigue の回復**に乗る
- **後半（15〜28日）**：回復の必要はない。それでもやる＝**行為自体が目的**。結果は **`bond`**（二人だけの世界の密度・完全非公開）に乗る
- 転換は**台詞で明示する**。「もう、疲れてはいないのですけれど」——それでも求めてくる

> ⚠️ **「14日目＝偽りの結末」は廃止されました（2026-07-20）。** 14日目は**小さな結婚式（他人の式）**の日であり、エンディングの選択は**28日目**にある。
> ただし「疲労が取りきった地点で、もう回復させる必要がないのにそれでも一緒にいる」という**動機の転換構造自体は維持**される。
> **「必要とされること」→「一緒にいたいこと」への転換**が、日数構成と隈のカーブで同時に起きる。

# 6. オート機能

2つに分ける。

| 種別 | 採否 | 仕様 |
| --- | --- | --- |
| テキストのオート送り | 採用 | 通常のノベルゲーム同様 |
| ミニゲームのオート | 採用 | **結果を「平均的な回復」に固定**する（最高でも最低でもない）。手動で上手くやる意味を残しつつ、詰まらない |

R-18の実プレイ環境では、片手が塞がっている・集中が続かないのは**想定すべき通常状態**。アクセシビリティではなく**商品として必須の設計**とする。

# 7. 枚数の算数

- ベース 4枚 ＋ 差分レイヤー（目／口／汗・湯気／隈）＋ **Zの決壊1枚**
- レイヤー合成のため、パーツを足しても点数は掛け算にならない。フルCG換算で 10枚前後
- 28日 ÷ 4ポジション ＝ 1ポジションあたり平均 7夜（実際はプレイヤーの選択による）

# 8. 夜の記録（nightRecords）との接続（2026-07-20 追記）

夜ケアの結果は、**完全公開の記録パラメータ `nightRecords`** にも記録される（「様子を見る」夜画面で表示）。

- **`???`** ＝未解放／**`0回`** ＝解放済みだが未発生（**unlocked フラグで管理**。「0なら???」にしない）
- 項目（記号管理）：KI / KO / SE / TA（**順次解放**）＋ S / Z（初夜から解放）
- **拡張可能な定義データ構造**で持つ（項目追加が1行で済む形）。**本ミニゲームの設計を詰めると項目が増える見込み**
- 順次解放の条件は「**夜ケアの累積成果（careStage 到達度 or 成功回数）＋日数下限**」で**仮置き**。★本ミニゲーム確定時に正式に決める
- ⚠️ 「心身の余白（上限）を解放条件にする」案は**却下済み**（上限値は現状変動しない・役割が濁る・「ケアの成果」ではなく「主人公の余裕」であるため）
- ★**裏エンディングの解放条件（2026-07-29 改訂）**：**29日目以降（28日目のエンディング後）に貯めた nightRecords が閾値到達** または **99日経過** の **OR条件**。本編28日間の数値は算入しないため、**本編中に夜を稼ぐ動機は生まれない**。99日到達時は強制発生（詰み防止の安全弁）
	- ※ フリープレイは**裏エンドの後**に解放される。旧記述「フリープレイ突入後の nightRecords」は無効
