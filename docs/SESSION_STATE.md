## エンディング（2026-07-27 改訂：「達成」から「選択」へ）

**無条件で常に選べる2つ**

- **役割なく残る**（新設）：天使様は引き止めの言葉を伝えるが、**最後の一言を言うのは主人公**
- **帰任する**：自分の意志で帰る（"届かなかったから"ではない）

**条件を満たすと増える2つ**

- **祈りエンド**：`祈りの調律` 閾値 ＋ 疲労ゲート
- **世話役エンド**：`世話役適性` 閾値 ＋ 疲労ゲート

**帰還の内部分岐**：疲労低＝天使様が語りかけて引き止める（はい→なにもなかったエンド／いいえ→残る系に戻る）／疲労高＝即なにもなかったエンド

⚠️ `信頼` は判定材料から除外（前半の推進役・痛みの入口として存続）。`bond` は非公開のまま判定に使わない。

## 夜ケア（コア確定・2026-07-22）

- **昼の心身の余白 → その割合で夜の精力を算出**（ゲージではなく数字）
- 夜は**基本オート**。能動は**残った余白を精力へ追加変換すること**だけ → **2発目**が可能に
- **夜は回避できない**。おあずけは選べるが、**3日で天使様の我慢が効かなくなる**
- ★**おあずけの解禁条件：信頼50以上 ＋ 8日目以降**（2026-07-29）。断れないこと自体が症状であり、解禁は症状が軽くなった証
- ★**夜なしの日**：7日目（告白の夜・エロなし）／21日目（葬儀）。**14日目は逆に強制**
	- 強制の夜なしは**おあずけの連続カウントに算入しない**
- ★**疲労の回復量は昼の余白から導出**（段階5・2〜6）。「昼に怠けて、夜に捧げる」
- 絵は**レイヤー合成方式**（ベース4＋目／口／汗・湯気）＋**Zの決壊1枚**（輪郭ごと描く）
- **開眼は廃止**。夜も切れ長／妖艶を使う

## 痛み（painPoints・5軸）

- **主体は【プレイヤー】**。5軸：useless / not_needed / no_rest / no_place / self_blame（loss は背景の通奏低音）
- ★**useless と not_needed を分離**（2026-07-27）。useless＝自分の能力を語る／not_needed＝他者の不在を語る。**天使様の返しも書き分ける**
- **入口は3つ**：**信頼解禁の会話イベント（主軸）**／食事イベント（初回のみ）／7日目の告白
- ★**行動の偏りからの回収も併用**（完全受動の入口）
- 答えは **memoryFlags** に記録し後で返す。**深い反映は2〜3個に絞る**
