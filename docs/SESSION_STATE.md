### 夜ケア
- **ゲーム性を確定**：コアの動詞＝**「持ちこたえる」**（抗うではない）。耐えた量＝ angelFatigue の回復量。ミニゲーム1種のみ（主導権の反転なし）。ゲームオーバーなし・精度判定表示なし
- **ポジション4つ**：進行で置き換わるのではなく**選択肢として累積**し、以降いつでも切替可能。**性能差なし**
- **「今夜の求め」**：ポジションが2〜3に増えた段階から**時折**発生。開始前の立ち絵会話で**それとなく**ヒント。応えれば**僅かな**ボーナス。応えなくてもペナルティなし
- **全28夜がケア対象＋「おあずけ」択**：おあずけ＝ angelFatigue が回復しない（翌日の余白が減る）が、**天使様は咎めない**
- **オートは2種に分離**：テキスト送り＝通常採用。ミニゲームのオート＝採用するが、結果を**「平均的な回復」に固定**
- **絵は1枚絵ベース（U-07 クローズ）**：ベース4枚（ポジション別）× 差分5枚。差分は「表情バリエーション」ではなく**状態連動**として持つ
- **動機は前半後半で入れ替わる（D-20）**：天使様の疲労は **14日目前後で概ね取り除ける**。前半＝回復させるためにやる（結果は angelFatigue に乗る）、**後半＝回復の必要はないが、それでもやる＝行為自体が目的**（結果は**別の値**に乗る）。転換は台詞で明示する
- ⚠️ **厳守**：夜ケアで回復するのは **angelFatigue（天使様の疲労）**であって、**主人公の painType ではない**。この2つを混ぜない（アンチパターン「痛みの数値ゲージ化とゼロ到達＝クリア」に抵触させない）

- **時間帯**：夕方＝天使様のお仕事（祈り）の時間。**正体判明も夕方**
