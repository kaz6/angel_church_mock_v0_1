# 0. 中心にある一行

> **特別な存在なのに、生活が不器用。**

- 信仰対象なのに、宂れた湯殿で一人細々と暮らしていた（格式と生活力のギャップ）
- 呪いを孿し、それを申し訳なく思う（聖性と後ろめたさ）
- 祈りで戦線を援護し、疲れきっている（気丈だが限界）
- 「あなたが来てから湯が温かい」——一人だと自分の世話が回っていなかった

その不器用さが、主人公に「必要とされる」余地を作る。完疒な天使なら世話役は要らない。**不器用だから居場所が生まれる**。台詞・イベント設計はこの一行を拠り所にする。

# 1. 基本設定

- 表向きは辺境教会のシスター。その実、天使。大昔からこの地を見守り、日課の祈りで世界の均衡を保っている
- 大教会（本部）から世話役が派遣される程度に特別扱いされている＝**信仰対象そのもの**でもある
- 主人公は大教会から派遣された世話役。天使様と同じ個室で同棲する
- 教会本部は「夜の関係」を知らない。**二人だけの契約**

# 2. 呪い（内部設定・要秘匿）

- 天使様は**性的な行為が必要不可欠になる呪い**を孿している。申し訳なく思いつつ、主人公と身を重ねる
- 求めるのは天使様の側であり、罪悪感を伴う。「してやる」ではなく「させてもらう／してもらう」の力関係
- 本部はこの呪いを知らず、性別問わず世話役を適当に送っていた（前任は女性で、天使様は困っていた）
- **羽の付け根の黒は、この呪いの暗喩**（純白でない＝聖なる存在が性を孿す）

# 3. 祈りと疲労（内部設定）

- 夕方の祈りは、遠くの戦線（アンチミームとの戦い）への遠隔援護。その負担で疲れている
- そこに現れた主人公に内心安堵している（＝夜ケアで疲労が回復する動機の物語的裏付け）
- 祈りはこの地を守る防波堤の一つ
- ⚠️ アンチミーム云々は**本作では明示しない**（別プロジェクトとの世界観接続で風呂敷が広がるため）。設定として持つに留める

# 4. キャラクター記号（造形・確定）

- **シスター服ベース**。既存の宗教モチーフ（†・✡等）は一切使わない
- **糸目**。基本は糸目、感情や状況に応じて**切れ長**。さらに終盤中心の特別プリセットで**妖艶**
	- ★**2026-07-21 呼称変更**：旧「半目」→**切れ長** ／ 旧「妖艶半目」→**妖艶**。作者が好むのは目の開度ではなく**目の形（切れ長）**。★**発注時は「半目」と言わず「切れ長・目尻を効かせて」と伝える**（「半目」は眠そうな半開きと誤解される）
- **目の隈**。物語の進行とケアの結果で増減する
- **背中の衣服に横一線の切れ目**。通常は意匠に見える（＝伏線として常に見えている）
- **翼は普段は不可視**。夕方の祈りの時に、切れ目から顕現する（無から出現＝より超常的）。冒頭のハプニングで判明
- **翼：白・付け根（生え際）が黒**。翼が顕現した時にのみ描かれる。付け根の黒もその時に露わになる
- 髪は長め（桛く・背を隠す・かき上げる演出のため）。**うさ耳風の毛束**を持ち、感情で動く（下記・ウサギモチーフ参照）
- **配色（確定）**：服＝**黒** ／ ヴェール＝**黒** ／ 髪＝**明るめブラウン** ／ 垂れ耳の毛先＝**黒（はっきり分ける。グラデーションにしない）** ／ 翼＝**白＋付け根黒** ／ 差し色＝**金（腰のチャーム）**
- **目の色**：通常＝ブラウン ／ **妖艶時＝桃色**（色気ではなく**本性の露見**。夜の後半で使う）
- ★**教会（天使様）のシンボルマーク ＝ 青い炎環**（2026-07-29）。夕方の祈りで、周囲に置いたロウソクの火が繋がって**一つの輪**になり、その中央で天使様が祈る
	- 環＝終わりがない＝**永遠**（裏エンドで受け取るネックレスと形が一致する）
	- ロウソク（燃料）は燃え尽きるが輪（火）は残る＝**天使様と村人の関係そのもの**
	- 青の根拠：炎の**外炎（青）＝完全燃焼・最高温**。無重力では炎は**青い球**になり、すすが出ず**ゆらがない**（NASA）＝地上の火とは別物の聖なる火
	- ⚠️ **未確定**：月チャームとの関係（どちらが紋章の座を取るか）／差し色の金に青が加わる件。**提案＝青は祈りの時だけ現れる色にする**（昼＝黒と金／夕方＝青／夜＝桃色）
- 独自宗教のアイコン（魔法陣等）は使用可。実在宗教モチーフは不使用

## 翼まわり（発注時のメモ）

- **立ち絵には翼を描かない**（普段は不可視）。切れ目だけが背中にある
- 翼は「祈りの場面のイベントCG」でのみ顕現。付け根の黒もそこで描く
- → 立ち絵11レイヤーに翼の差分は不要。発注量が減る
- 翼を描くCG側では、切れ目・翼の生え際・付け根の黒が近接するため、位置関係を明示する

## ウサギモチーフ（意匠メイン・D-46）

うさぎを**意匠（見た目・仕草の味付け）として**入れる。設定（天使の性質）にはしない。三方向に刃さる：

- **草食** → 丙齒り（野菜をそのまま齒る）の回収
- **多産・性欲が強い** → 呪い（性が必要不可欠）の暗喩。可愛い記号で性の業をやわらかく包む
- **耳（髪）の感情表現** → 糸目で目が動かない弱点を補う

白うさぎの清らかさ ↔ 羽の付け根の黒（呪い）のコントラストが、うさぎでも反復される。宗教モチーフを封じた分のキャラ固有の記号（D-14の課題）をうさぎが埋める。

## ロップイヤー（垂れ耳）風の髪の動き（発注要件）

**垂れ耳（ロップイヤー）型を採用。髪の毛束として表現する（ヴェールではない）。**

- **垂れ耳を選ぶ理由**：①立ち耳は元気・活発でチルの温度から浮くが、垂れ耳は「隠す・伏せる」で糸目・控えめな天使様と揃う ②垂れるので長い髪の房として自然に成立し、「言われないと気づかないが、言われるとうさぎに見える」＝意匠メインの狙いに合う ③動きの幅が小さくて済み、繊細さ・慎ましさが出る
- **感情表現の文法（垂れ耳版）**：平常＝垂れたまま／喜び・興味＝わずかに持ち上がる・ぴくっと跳ねる／強い喜び＝ふわっと浮く／不安・悲しみ＝さらに深く垂れる・内側に丸まる／驚き＝びくっと震える
- **疲労表現に流用可**：垂れ耳の「重みで垂れている」質感を使い、angelFatigue が高い日は耳が重く垂れ、回復すると軽く跳ねる（隈と同じ導出値で駆動でき、差分を増やさず状態表現が増える）
- 髪に乗せる理由（ヴェールでない理由）：**夜ヴェールを脱いだときも耳が残る**。昼＝覆われた聖性／夜＝剥き出しの無防備が耳１つで表現できる。また「理性で制御できない本能の露見」は、着脱可能な布より身体の一部（髪）の方が強い
- **表情と耳のギャップ**も演出になる（顔は涼しいのに耳は嬉しがっている）
- 髪の動きはプログラムで揺らせる（湯気レイヤーと同発想）
- ⚠️ 発注要件：**ロップイヤー風の毛束を「動かせるレイヤー」として分離**（表情差分と同じPSDレイヤー分離）
- ❗ **ロップイヤー内側にピンクは入れない**（桃色を目に集中させるため。耳のうさぎ感は形と毛先の黒で十分）

# 5. 表情システム（確定・D-18）

レイヤー分離／PSD納品で合成する。**立ち絵1ポーズあたり 計 11 レイヤー**。

- **目：3枚** — 糸目 / **切れ長** / **妖艶**
- **隈：2枚** — 薄 / 濃（αクロスフェードで無段階に見せる）
- **感情セット（口・眉・頬・涙）：6枚** — 平常 / 笑 / 大笑 / 怒（頬膛らませ）/ 悲 / 驚

⚠️ **開眼は廃止**（2026-07-21）。**夜CGでも立ち絵と同じ目（糸目／切れ長／妖艶）を使う。** カッと見開く表情は作らない。

- 理由は作者の好み。「目を開かせない」ことではなく**切れ長の目そのものが好き**であり、見開くとその魅力が消える
- 昼夜のギャップは「開眼の有無」ではなく **目の色（ブラウン→桃色）＋吐息・汗・頬の赤み** で担保する
- 旧記述「糸目 → 半目 → 妖艶半目 →（夜CGで）開眼 の4段グラデーション」は**無効**

## 妖艶の運用

- プリセット制。日常プリセット（平常/笑/大笑/怒/悲/驚）は目が糸目・**切れ長**のみで、**妖艶**を含まない
- **妖艶**は特別プリセット限定・終盤中心・全28日で3〜5回。判断基準＝「天使様が主人公を必要としていることが漏れる瞬間」

## 隈の駆動（D-17）

- 隈は状態変数ではなく **angelFatigue からの導出値**
- 昼の立ち絵：その日の朝の angelFatigue でスナップショット固定／夜のCG：リアルタイム
- 長期変化は「疲労蓄積レートの低下」で表現。OPはシステム外

# 6. 夜CGの差分駆動（D-20 / D-34）

- ★**レイヤー合成方式（2026-07-21 確定）**：ベース4枚（ポジション別）の上に、**目／口／汗・湯気**を独立レイヤーで重ねる。各パーツ数枚ずつで、組み合わせにより多彩な表情が出る
- ★**口は輪郭が動く**ため、単純なレイヤー重ねでは破綻する。対策は **B＋C**：
	- **B（普段）**：開口の段階を**輪郭が動かない範囲**に絞る（引き結ぶ／薄く開く／息が漏れる）。切れ長の目の美学と一致し、素材も軽い
	- **C（ここぞ）**：**Z（天使のクライマックス）の瞬間だけ**、輪郭ごと描いた専用の顔を1枚差し込む。口が大きく開き、妖艶＋桃色になる。**全ての抑制が一点で決壊する1枚**
- **湯気は汎用エフェクトレイヤー**を流用（食卓／浴室／夜CGで共用。露出コントロールにも使える）
- **前半：隈 ← angelFatigue**（回復の物語）
- **後半：表情・汗・目のハートマーク ← bond**（密度の物語）
- 14日目で駆動の主役が交代。同じベースCGが前半＝疲れが取れた顔／後半＝満たされた顔に変わる
